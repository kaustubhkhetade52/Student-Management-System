# Student Management System 

A simple menu-driven Student Management System developed using C++. It allows users to manage student records through basic operations such as adding, displaying, searching, updating, and deleting student information.

## Features

- **Add Students:** Enter student details such as name, roll number, course, class, and contact number.
- **Display Records:** View all stored student information.
- **Search Students:** Find a student using their roll number.
- **Update Records:** Modify existing student details.
- **Delete Records:** Delete a specific student's record or all records.
- **Menu-Driven Interface:** Perform operations through a simple console-based menu.

## Technologies Used

- C++
- Arrays
- Functions
- Loops and Conditional Statements
- Switch Case
- String Handling

## Concepts Implemented

This project demonstrates the use of functions, arrays, loops, conditional statements, and basic CRUD (Create, Read, Update, Delete) operations in C++.

## Limitations

- Stores a maximum of 20 student records.
- Data is stored temporarily in arrays and is not preserved after the program terminates.
- Student names and other string inputs do not support spaces.
